# SAP HANA Administration & Monitoring Portfolio

Hands-on project demonstrating practical SAP HANA Cloud administration skills — provisioning, user management, security, monitoring, and troubleshooting.

## Environment
- SAP BTP Trial (Multi-Environment)
- SAP HANA Cloud, Free Tier
- Instance: `HANA-ADMIN-LAB`
- Region: AWS US East (VA)

## Project Structure
- `configs/` — Instance configuration exports
- `docs/` — Provisioning, user admin, monitoring, troubleshooting notes
- `sql-scripts/` — SQL scripts used throughout the project
- `evidence/` — Screenshots and diagnostic outputs
